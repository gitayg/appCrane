# Contributing to AppCrane

Thanks for your interest in improving AppCrane. Bug reports, feature ideas, and
pull requests are all welcome.

## Ground rules

- Open an issue before large changes so we can align on the approach.
- Keep pull requests focused and match the surrounding code style.
- Don't add comments, docstrings, or type annotations to code you didn't change.
